Portfolio Website — Hand-Coded From Scratch

A fully hand-crafted personal portfolio website built with HTML, CSS, JavaScript, and GSAP for smooth scroll-based animations.
No frameworks, no templates — everything was implemented manually to understand layout, responsiveness, animations, and UI logic from the ground up.

🚀 Features

Custom layout built from scratch (no Bootstrap/Tailwind).

GSAP scroll animations for hero elements and section transitions.

Responsive design for desktop and mobile.

Interactive navigation with smooth user flow.

About, Projects, and Contact sections with organized content blocks.

Glass-blur UI elements using backdrop-filter.

Functional contact form (JS-based handler).

Optimized images (webp/png) for faster loads.

Clean, readable code following basic best practices.

🛠️ Tech Stack

Frontend:

HTML5

CSS3 (Flexbox, gradients, blur effects)

JavaScript (DOM manipulation, event listeners)
